    NMF¶

    Non-negative matrix factorisation of the counts into gene programmes.

    HALS NMF, factorising genes by cells into gene loadings (w, genes by k) and cell usages (h, k by cells). One run, random restarts, consensus NMF in the cNMF style, and a sweep over k.

    Start with nmf_k_sweep to pick k: it runs the consensus step for every k in the range and returns stability and reconstruction error per k. High stability while the error is still falling is the sweet spot. Then fit consensus_nmf at that k. nmf is one run, stabilised_nmf keeps all the random restarts and get_best_run pulls out the lowest-loss one.

    What lands where. Nothing is written to the experiment. Every function returns a result object, and get_w gives the gene loadings as a frame. get_data turns the cell usages of an NmfResult or ConsensusNmfResult into an obs frame, one comp_XX column per component, for sc.add_obs. All functions take a SingleCells, a SingleCellsSubset or a MetaCells. Genes default to the HVGs, so run bv.pp.find_hvg first or pass gene_ids; cells default to the kept ones.

    bv.pp.find_hvg(sc, hvg_no=500)
sweep = bv.nmf.nmf_k_sweep(sc, k_range=range(3, 8), n_runs=10)
sweep.frame
res = bv.nmf.consensus_nmf(sc, k=5, n_runs=10)
sc.add_obs(bv.nmf.get_data(res))
loadings = bv.nmf.get_w(res)

    Gotchas. The factorisation uses the normalised counts; pass use_second_layer=False for the raw ones. The consensus step needs k and n_runs of at least 2 and raises when the restarts do not agree, with a message on what to change (a higher density_threshold in NmfConsensusParams, more runs, another k). In nmf_k_sweep a failing k gets a null stability and a warning instead. consensus_target="w" clusters in cell space and gets expensive past 20,000 cells. Indices are 0-based, the comp_XX and component_id names count from 1.

    Worked through in Gene set analysis and GRN inference on PBMCs.

    Consensus HALS NMF (cNMF).

    Pools the components of n_runs random restarts, drops the ones in sparse neighbourhoods, clusters the rest into k programmes and takes each cluster's median; the usages are refit against it. The k-means of the consensus step is seeded from seed.

    Parameters:

    Name Type Description Default
    sc ScOrMc

    The experiment, a subset or meta cells.

    		 required
    k int

    Number of components, at least 2.

    		 required
    cell_ids Sequence[str] | None

    Cell (meta cell) ids. None for the kept cells.

    		 None
    gene_ids Sequence[str] | None

    Gene ids. None for the HVGs.

    		 None
    preprocessing Preprocessing

    "none", per gene "sd" or "sqrt_sd" scaling.

    		 'none'
    use_second_layer bool

    Factorise the normalised rather than the raw counts.

    		 True
    nmf_hals_params NmfHalsParams | None

    The solver.

    		 None
    nmf_consensus_params NmfConsensusParams | None

    The consensus step. None uses the defaults.

    		 None
    n_runs int

    Number of restarts, at least 2.

    		 30
    seed int

    Base seed of the restarts and the consensus k-means.

    		 42
    verbose Verbose

    0 (False) silent, 1 (True) progress, 2 extra detail where the method has it.

    		 True

    Returns:

    Type Description
    ConsensusNmfResult

    The ConsensusNmfResult.

    Raises:

    Type Description

    Kotliar, et al., eLife, 2019.

>>> sc.add_obs(bv.nmf.get_data(res))
>>> stability = bv.nmf.get_stability(res)

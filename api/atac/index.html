    ATAC¶

    Single cell ATAC: peak or tile counts, QC, TF-IDF, LSI, links to genes.

    Two kinds of experiment hold ATAC:

    • a SingleCellsMultiModal with RNA: the ATAC counts live in a second store under atac/, written for every cell of the RNA store in the same order, so the RNA cell filter applies to both. bv.mm.generate_wnn_graph fuses the two.
    • a SingleCellsAtac, ATAC only: the peaks or tiles are the experiment's own store. Load one with bv.io.load_atac_fragments or bv.io.load_atac_tenx.

    Every function here takes either. From the LSI on, the regular single cell functions take modality="atac" and embd_to_use="lsi"; on a SingleCellsAtac the default modality means the ATAC store as well.

    # multiome
mm = bv.SingleCellsMultiModal(sc.dir)
bv.atac.add_atac_tenx(mm, "filtered_feature_bc_matrix.h5")
bv.atac.fragment_qc(mm, "atac_fragments.tsv.gz", "genes.gtf.gz")
bv.atac.run_tfidf(mm)
bv.atac.find_top_features(mm, min_cutoff="q5")
bv.atac.calculate_lsi(mm, n_comp=30)
bv.mm.generate_wnn_graph(mm, modality_2="atac", embd_to_use_2="lsi")

# ATAC only
counts = bv.atac.barcode_fragment_counts("atac_fragments.tsv.gz")
x = bv.io.load_atac_fragments(
    "exp", "atac_fragments.tsv.gz", peaks="peaks.bed", min_fragments=1000
)

    Peaks or fragments. add_atac_tenx takes the peak matrix Cell Ranger ARC wrote into the h5. add_atac_fragments counts the fragment file itself into a BED of peaks or fixed-width tiles; its default mode="insertion" counts each Tn5 insertion as Cell Ranger does, and reproduces the h5 matrix on Cell Ranger's peaks.

    Calling peaks. call_peaks calls peaks on the fragments per cluster (group_by), a native port of MACS3 callpeak (exact coordinates and summits against MACS3 3.1.0); Cell Ranger's peak set under-calls rare populations. remove_blacklisted drops peaks on blacklist regions before the result goes into add_atac_fragments(peaks=...). annotate_peaks names each feature's closest gene.

    Barcodes and files. Fragment barcodes are the cell ids unless barcode_map says otherwise (a -1 suffix, a sample prefix). merge_fragments merges per-sample fragment files into one, barcodes prefixed per sample, as cellranger-arc aggr does. Every fragment pass errors when no cell id is a barcode of the file or the fragments and the features share no chromosome name, and warns on partial mismatches.

    Multiplets. amulet flags multiplets from loci where more than two of a cell's fragments overlap (AMULET); it needs no clustering and no RNA. Pass repeat and blacklist BEDs as restrict_beds.

    Gene activity. gene_activity counts fragments over gene body plus promoter (Signac's GeneActivity) into its own SingleCells, the query side of an RNA to ATAC label transfer; get_gene_activity reopens it with the experiment's cell filter. It is not RNA: methods that assume an mRNA count model (residuals, doublets, Bonsai, gene set proportions) refuse it, and those biased by gene length or by fragments shared between neighbouring genes (AUCell, ScType, lm_activity, NMF, Hotspot gene correlations, SCENIC, CellPhoneDB) warn. Peaks and tiles are refused by every method that works on genes.

    Links and profiles. peak_to_gene correlates peaks with nearby genes over groups of cells (ArchR's peak to gene links). fragment_profiles gives the TSS insertion profile and the fragment length histogram per group, for bv.pl.tss_profile_plot and bv.pl.fragment_length_plot.

    Mapping and integration. project_lsi puts a query onto a reference LSI (Seurat's lsiproject); run_rlsi integrates batches through reciprocal LSI anchors. bv.integrate.harmony(x, "batch", embd_to_use="lsi", modality="atac") corrects the LSI instead and writes "harmony" to the ATAC cache.

    Gotchas. run_tfidf computes the IDF over the kept cells: run it again, then the LSI, after changing them; it also clears the ATAC cache. calculate_lsi drops component 1 by default, as the Signac vignettes do; get_lsi_depth_cor and bv.pl.lsi_depth_plot show whether that is right for the data.

    Worked through in Joint RNA and ATAC and ATAC without RNA. The ATAC-only loaders, bv.io.load_atac_fragments and bv.io.load_atac_tenx, are on the I/O page; the SingleCellsAtac class on the core page.

    AtacInfo dataclass ¶

    AtacInfo(
    kind: Literal["peak", "tile"],
    count_mode: CountMode,
    tf_idf: bool = False,
    depth_cor: ndarray | None = None,
    lsi_dropped: tuple[int, ...] = (),
    lsi_features: ndarray | None = None,
    lsi_loadings: ndarray | None = None,
    lsi_singular_values: ndarray | None = None,
)

    What the ATAC store holds and how far it was processed.

    Attributes:

    Name Type Description
    kind Literal['peak', 'tile']

    "peak" or "tile".
    count_mode CountMode

    What one count is: "insertion" (up to two per fragment), "paired-insertion" or "fragment" (one per fragment and feature). The 10x Peaks matrix counts insertions.
    tf_idf bool

    Whether the store is TF-IDF normalised.
    depth_cor ndarray | None

    Correlation of each LSI component with the library size, all components including any dropped one.
    lsi_dropped tuple[int, ...]

    0-based LSI components left out of the "lsi" embedding.
    lsi_features ndarray | None

    0-based ATAC feature rows the LSI was fitted on.
    lsi_loadings ndarray | None

    Features x components loadings of the LSI, all components, for projecting other cells onto it.
    lsi_singular_values ndarray | None

    Singular values of the LSI.

    tile_width: int | None = None,
    chrom_sizes: Mapping[str, int] | None = None,
    mode: CountMode = "insertion",
    barcode_map: BarcodeMap = None,
    overwrite: bool = False,
    max_mem_gb: float | None = None,
    verbose: Verbose = 1,
) -> None

    Count a fragment file into peaks or genome tiles as the ATAC store.

    Parameters:

    Name Type Description Default
    mm SingleCellsMultiModal

    The experiment; every cell of its store is counted.

    		 required
    fragments Path | str

    The fragment file (BGZF, gzip or plain).

    		 required
    peaks Path | str | DataFrame | None

    A BED file or a frame with chrom, start, end (0-based, half-open).

    		 None
    tile_width int | None

    Tile width in bp, instead of peaks.

    		 None
    chrom_sizes Mapping[str, int] | None

    Chromosome lengths, for the tiles.

    		 None
    mode CountMode

    "insertion" (each Tn5 insertion, Cell Ranger and ArchR), "paired-insertion" (once per fragment and feature, SnapATAC2) or "fragment" (each overlapping fragment, Signac).

    		 'insertion'
    barcode_map BarcodeMap

    Cell id to fragment barcode, where they differ.

    		 None
    overwrite bool

    Replace an existing ATAC store.

    		 False
    max_mem_gb float | None

    Memory budget of the peak-major conversion.

    		 None
    verbose Verbose

    0 silent, 1 normal, 2 detailed.

    		 1

    Raises:

    Type Description
    FileExistsError

    If an ATAC store exists and overwrite is false.
    ValueError

    Unless exactly one of peaks and tile_width is given, if tiles come without chrom_sizes, if a peaks frame lacks chrom, start or end, if no cell id is a barcode of the file, or if no fragment lies on a chromosome of the features.

    merge_fragments ¶

    merge_fragments(
    fragments: Sequence[Path | str],
    out: Path | str,
    *,
    prefixes: Sequence[str] | None = None,
    suffixes: Sequence[str] | None = None,
) -> DataFrame

    Merge per-sample fragment files into one, as cellranger-arc aggr does.

    Each file's barcodes get its prefix and suffix, so the same barcode in two samples stays two cells; give every file its own. The output is a sorted BGZF file with a tabix index, which every function here reads as one experiment. Files with a tabix index are read one chromosome at a time; others are held in memory whole.

    Parameters:

    Name Type Description Default
    fragments Sequence[Path | str]

    The fragment files.

    		 required
    out Path | str

    The merged file; the index goes next to it as .tbi.

    		 required
    prefixes Sequence[str] | None

    Barcode prefix per file, e.g. ["s1_", "s2_"].

    		 None
    suffixes Sequence[str] | None

    Barcode suffix per file, e.g. ["-1", "-2"] after stripping 10x's own suffix with a prefix of "".

    		 None

    Returns:

    Type Description
    DataFrame

    fragments, prefix, suffix and n_fragments per input.

    Raises:

    Type Description
    ValueError

    If neither prefixes nor suffixes is given, or their lengths do not match the files.

    Flag multiplets from fragment overlaps (AMULET), written to obs.

    A diploid nucleus yields at most two overlapping fragments at a locus. Per cell, the loci with more are counted (autosomes, restriction regions dropped), sites shared by too many cells are dropped as repeats, and the count is tested against the mean (Poisson, Benjamini-Hochberg). Implemented from Thibodeau et al. (Genome Biology, 2021); on the test data it reproduces the reference implementation's counts and p-values. Needs no clustering and no RNA, so it works for ATAC-only experiments. Run it per library: multiplets are a property of one capture.

    Adds amulet_n_overlaps, amulet_n_sites, amulet_p, amulet_q and amulet_multiplet for every cell of the store.

    Peaks¶

    Single cell ATAC: peak or tile counts, QC, TF-IDF, LSI, links to genes.

    Two kinds of experiment hold ATAC:

    • a SingleCellsMultiModal with RNA: the ATAC counts live in a second store under atac/, written for every cell of the RNA store in the same order, so the RNA cell filter applies to both. bv.mm.generate_wnn_graph fuses the two.

    "exp", "atac_fragments.tsv.gz", peaks="peaks.bed", min_fragments=1000

    Peaks or fragments. add_atac_tenx takes the peak matrix Cell Ranger ARC wrote into the h5. add_atac_fragments counts the fragment file itself into a BED of peaks or fixed-width tiles; its default mode="insertion" counts each Tn5 insertion as Cell Ranger does, and reproduces the h5 matrix on Cell Ranger's peaks.

    Calling peaks. call_peaks calls peaks on the fragments per cluster (group_by), a native port of MACS3 callpeak (exact coordinates and summits against MACS3 3.1.0); Cell Ranger's peak set under-calls rare populations. remove_blacklisted drops peaks on blacklist regions before the result goes into add_atac_fragments(peaks=...). annotate_peaks names each feature's closest gene.

    Barcodes and files. Fragment barcodes are the cell ids unless barcode_map says otherwise (a -1 suffix, a sample prefix). merge_fragments merges per-sample fragment files into one, barcodes prefixed per sample, as cellranger-arc aggr does. Every fragment pass errors when no cell id is a barcode of the file or the fragments and the features share no chromosome name, and warns on partial mismatches.

    Multiplets. amulet flags multiplets from loci where more than two of a cell's fragments overlap (AMULET); it needs no clustering and no RNA. Pass repeat and blacklist BEDs as restrict_beds.

    Gene activity. gene_activity counts fragments over gene body plus promoter (Signac's GeneActivity) into its own SingleCells, the query side of an RNA to ATAC label transfer; get_gene_activity reopens it with the experiment's cell filter. It is not RNA: methods that assume an mRNA count model (residuals, doublets, Bonsai, gene set proportions) refuse it, and those biased by gene length or by fragments shared between neighbouring genes (AUCell, ScType, lm_activity, NMF, Hotspot gene correlations, SCENIC, CellPhoneDB) warn.     Links and profiles. peak_to_gene correlates peaks with nearby genes over groups of cells (ArchR's peak to gene links). fragment_profiles gives the TSS insertion profile and the fragment length histogram per group, for bv.pl.tss_profile_plot and bv.pl.fragment_length_plot.

It is not RNA: methods that assume an mRNA count model (residuals, doublets, Bonsai, gene set proportions) refuse it, and those biased by gene length or by fragments shared between neighbouring genes (AUCell, ScType, lm_activity, NMF, Hotspot gene correlations, SCENIC, CellPhoneDB) warn. Peaks and tiles are refused by every method that works on genes.

    Links and profiles. peak_to_gene correlates peaks with nearby genes over groups of cells (ArchR's peak to gene links). fragment_profiles gives the TSS insertion profile and the fragment length histogram per group, for bv.pl.tss_profile_plot and bv.pl.fragment_length_plot.

    Mapping and integration. project_lsi puts a query onto a reference LSI (Seurat's lsiproject); run_rlsi integrates batches through reciprocal LSI anchors. bv.integrate.harmony(x, "batch", embd_to_use="lsi", modality="atac") corrects the LSI instead and writes "harmony" to the ATAC cache.

    Gotchas. run_tfidf computes the IDF over the kept cells: run it again, then the LSI, after changing them; it also clears the ATAC cache. calculate_lsi drops component 1 by default, as the Signac vignettes do; get_lsi_depth_cor and bv.pl.lsi_depth_plot show whether that is right for the data.

    Link peaks to nearby genes by correlation over groups of cells.

    ArchR's addPeak2GeneLinks. Peak and gene counts are summed per level of group_by (fine clusters, or metacell assignments, of the kept cells), log-normalised per group, log2(x / total * 1e4 + 1), and correlated over the groups for every peak within max_distance of a gene's TSS. p-values are the two-sided t-test of each correlation, FDR Benjamini-Hochberg over all pairs.     Mapping and integration¶

    Single cell ATAC: peak or tile counts, QC, TF-IDF, LSI, links to genes.

    Two kinds of experiment hold ATAC:

    • a SingleCellsMultiModal with RNA: the ATAC counts live in a second store under atac/, written for every cell of the RNA store in the same order, so the RNA cell filter applies to both. bv.mm.generate_wnn_graph fuses the two.
    • a SingleCellsAtac, ATAC only: the peaks or tiles are the experiment's own store. Load one with bv.io.load_atac_fragments or bv.io.load_atac_tenx.

    Every function here takes either. From the LSI on, the regular single cell functions take modality="atac" and embd_to_use="lsi"; on a SingleCellsAtac the default modality means the ATAC store as well.

    # multiome
mm = bv.SingleCellsMultiModal(sc.dir)
bv.atac.add_atac_tenx(mm, "filtered_feature_bc_matrix.h5")
bv.atac.fragment_qc(mm, "atac_fragments.tsv.gz", "genes.gtf.gz")
bv.atac.run_tfidf(mm)
bv.atac.find_top_features(mm, min_cutoff="q5")
bv.atac.calculate_lsi(mm, n_comp=30)
bv.mm.generate_wnn_graph(mm, modality_2="atac", embd_to_use_2="lsi")

# ATAC only
counts = bv.atac.barcode_fragment_counts("atac_fragments.tsv.gz")
x = bv.io.load_atac_fragments(
    "exp", "atac_fragments.tsv.gz", peaks="peaks.bed", min_fragments=1000
)

    Peaks or fragments. add_atac_tenx takes the peak matrix Cell Ranger ARC wrote into the h5. add_atac_fragments counts the fragment file itself into a BED of peaks or fixed-width tiles; its default mode="insertion" counts each Tn5 insertion as Cell Ranger does, and reproduces the h5 matrix on Cell Ranger's peaks.

    Calling peaks. call_peaks calls peaks on the fragments per cluster (group_by), a native port of MACS3 callpeak (exact coordinates and summits against MACS3 3.1.0); Cell Ranger's peak set under-calls rare populations. remove_blacklisted drops peaks on blacklist regions before the result goes into add_atac_fragments(peaks=...). annotate_peaks names each feature's closest gene.

    Barcodes and files. Fragment barcodes are the cell ids unless barcode_map says otherwise (a -1 suffix, a sample prefix). merge_fragments merges per-sample fragment files into one, barcodes prefixed per sample, as cellranger-arc aggr does. Every fragment pass errors when no cell id is a barcode of the file or the fragments and the features share no chromosome name, and warns on partial mismatches.

    Multiplets. amulet flags multiplets from loci where more than two of a cell's fragments overlap (AMULET); it needs no clustering and no RNA. Pass repeat and blacklist BEDs as restrict_beds.

    project_lsi ¶

    project_lsi(
    reference: AtacHost, query: AtacHost
) -> ndarray

    Project the query's kept cells onto the reference LSI.

    Seurat's ProjectSVD(mode = "lsi") as FindTransferAnchors(reduction = "lsiproject") runs it: the query's own TF-IDF times the reference loadings, divided by the singular values, with no centring or scaling. The reference "lsi" embedding is z-scored, the projection is not; L2 normalise both per cell before comparing them, as Seurat does. Components the reference dropped are dropped here too. Either side may be multi-modal or ATAC-only.

    Written to query.atac_cache.embeddings as "lsi_projected".

    rLSI integration, Signac's FindIntegrationAnchors(reduction = "rlsi").

    Then IntegrateEmbeddings. Per batch: IDF over its own cells, TF-IDF and LSI of features; anchors between every batch pair in the reciprocal LSI spaces; then embedding is corrected along the anchor tree. Written to x.atac_cache.embeddings as "rlsi".

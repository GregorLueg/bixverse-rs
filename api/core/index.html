    Core¶

    The experiment classes and the objects they hand around.

    Single-cell streaming for Python, in Rust.

    Opens a bixverse binary sparse store and yields minibatches fast enough to keep a GPU training loop fed. The decode never leaves Rust: a feeder thread decompresses and materialises batches ahead of the consumer, releasing the GIL while it works.

    >>> import bixverse as bv
>>> reader = bv.CellReader("counts.bin")
>>> loader = bv.CellLoader(reader, batch_size=256, layer="norm")
>>> for batch in loader:
...     x = batch.scipy_csr()

    Batches are sparse CSR by default. Pass sparse=False for a dense (batch_size, n_genes) array, and expect it to cost a zero-fill and a scatter over every gene whether or not it holds a count.

    SingleCells ¶

    SingleCells(directory: Path | str)

    Bases: ScBase

    A single cell experiment on disk.

    The constructor rebuilds the map from the DuckDB (ids from obs / var, the cell filter from to_keep) with an empty cache, which is what load_existing() does when no memory file is present. Use bixverse.io.load_existing to also restore a saved cache.

    >>> import bixverse as bv
>>> sc = bv.io.load_existing("my_experiment")
>>> sc.obs(filtered=True)
>>> counts = bv.get_counts(sc, genes=["CD3E", "MS4A1"])

    set_cells_to_keep ¶

    set_cells_to_keep(cells: Selection) -> None

    Restrict the experiment to a set of cells.

    Updates the map and the to_keep column. The cells are stored unique and ascending; results align to that order, not the order given. Anything cached was computed on the old cell set; it is kept, not deleted, and a warning names what went stale.

    Parameters:

    Name Type Description Default

    0-based store indices or cell ids.

    		 required

    reset_cells_to_keep(*, force: bool = False) -> None

    Restore every cell, clearing the HVG selection and the cache.

    A PCA or kNN computed on a subset does not describe the full cell set, so nothing cached survives. A populated cache needs force=True.

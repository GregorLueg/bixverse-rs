    Parameters (GPU)¶

    The GPU-specific knobs. Everything else takes the bixverse.params bundles.

    params ¶

    Parameter bundles for the GPU twins.

    One frozen dataclass per parameter bundle the twins take, flat as Rust sees them. Generated from the parameter specs, except ScrubletGpuParams, which is hand-written. Twins with no GPU-specific knobs (PCA, SEACells, Bonsai, NMF, SCENIC) take the CPU bundles from bixverse.params; bixverse.params.to_rust serialises both.

    Wrapper function for parameters for GPU NEBULA

    GPU counterpart to NebulaParams. Same knobs and defaults, minus reml: the device fit does not implement it. Stage two of NEBULA, the per-gene penalised fits, runs in f32 on the device and is finished on the host in f64, so the estimates sit close to the CPU ones rather than on them.

    Attributes:

    Name Type Description
    nebula_method Literal['ln', 'hl']

    Which variant to run. NEBULA downgrades "ln" to "hl" below 30 cells per subject.
    min_sigma float

    Lower bound on the subject-level overdispersion.
    min_phi float

    Lower bound on the cell-level overdispersion.
    max_sigma float

    Upper bound on the subject-level overdispersion.
    max_phi float

    Upper bound on the cell-level overdispersion.
    cutoff_cell float

    Refit both overdispersions when the product of the cells per subject and the estimated phi falls below this.
    kappa float

    Threshold on NEBULA's kappa_obs above which the subject-level overdispersion from stage one is trusted as is.
    cpc float

    Drop a gene whose mean count per cell is at most this.
    mincp int

    Drop a gene expressed in fewer than this many cells.
    min_subjects int

    Drop a gene that fewer than this many subjects express, a subject expressing it when its own mean count per cell is above cpc. cpc and mincp pool every cell, so one subject can carry a gene through on its own. 0 switches the check off, as in the nebula package.
    eps float

    Absolute stopping tolerance for the optimiser.
    gene_batch_size int

    Genes read and fitted per batch. Bounds how much of the store is resident at once and changes nothing about the answer, since NEBULA is gene-independent.
    shrink_dispersion bool

    Shrink the cell-level overdispersions towards an empirical Bayes prior once the sweep is done.

    Default parameters for GPU fast clustering

    GPU counterpart to FastClusterParams. Fast clustering coarsens the cells with k-means, builds a graph over the centroids and runs Louvain or Leiden on it. The community of each centroid is handed back to its cells. Only the k-means (and the cell-mediated top-m search) run on the GPU. The mini-batch k-means knobs are gone: the GPU k-means is full-batch Lloyd's.

    Attributes:

    Name Type Description
    n_centroids int | None

    Number of k-means centroids. If None, defaults to floor(4 * sqrt(n_cells)).
    k_means_iter int

    Maximum number of k-means iterations.
    k_means_init str | None

    Initialisation method. One of "random", "parallel" or "plusplus". If None, picked on the Rust side based on the number of centroids.
    fixed bool

    Shall k-means run for a fixed number of iterations, without checking for convergence. wgpu only; MLX always runs every iteration.
    quantise bool

    Shall the data buffer be held at fp16 on the GPU. Halves the buffer and helps when the assignment kernels are memory bound. wgpu only.
    dist Literal['euclidean', 'cosine']

    Distance for the k-means and the centroid graph.
    cell_mediated bool

    Shall the cell-mediated centroid graph from Secuer be built instead of the kNN graph on the centroids. Centroids are then linked by the cells that sit near both, so two centroids that are close in space but have no cells between them stay apart. If True, centroid_k and centroid_graph are ignored.
    n_anchors int

    Number of nearest centroids each cell links to in the cell- mediated graph. Only used if cell_mediated = True.
    centroid_k int

    Neighbours per centroid in the exact centroid kNN. Only used if cell_mediated = False.
    knn_sym Literal['snn', 'umap', 'knn']

    How to symmetrise the kNN into a graph. Clustering resolutions do not carry over between the methods: the "umap" and "knn" graphs only hold kNN pairs, the sNN graph also links cells that share neighbours and prunes weak edges. The same resolution can give more or fewer communities depending on the data, so retune it when switching.
    snn_similarity Literal['jaccard', 'rank']

    "snn" only. "jaccard" weighs an edge by the Jaccard index of the two (self-inclusive) neighbour sets. "rank" takes the shared neighbour with the lowest combined rank, so closer shared neighbours give heavier edges. Both are scaled to [0, 1].
    pruning float

    "snn" only. Edges below this weight are dropped. For the Jaccard weight a threshold p keeps pairs that share at least a fraction 2p / (1 + p) of their (self-inclusive) neighbourhoods, rounded up to whole cells, so the same value means the same thing at any k. The default asks for about 12%, i.e. 2 of 16 shared cells at k = 15, in line with Seurat's 1/15. Avoid a threshold that equals one of the discrete weights exactly, or float rounding decides whether the edge survives.
    rescue bool

    "snn" only. Reconnect the small components that pruning cuts off via their strongest sNN edge, so they do not turn up as tiny clusters.
    local_connectivity float

    "umap" only. Number of nearest neighbours assumed to be fully connected, as in umap-learn.
    mix_ratio float

    "umap" only. 1 is the fuzzy union of the directed kNN memberships, 0 the fuzzy intersection (umap-learn's set_op_mix_ratio).
    binary bool

    "knn" only. If True, every edge weighs 1. Otherwise mutual neighbours weigh 2 and one-sided ones 1.
    algorithm Literal['louvain', 'leiden']

    Community detection on the centroid graph.
    n_iterations int | None

    Number of iterations of the community detection. A negative value iterates until stable. If None, the bixverse default for the chosen algorithm.
    beta float

    Leiden only. Randomness of the refinement step.
    min_gain float

    With a negative n_iterations, also stop once an iteration gains no more than this in modularity.
    local_moving Literal['queue', 'coloured']

    "queue" is Traag's sequential queue. "coloured" moves the nodes of one colour class in parallel, which only kicks in on larger levels of the graph.
    multi_level bool

    Shall the communities be aggregated and refined in levels.
    max_evals int

    Cap on the node evaluations per local moving phase, in units of the number of nodes.

    Default parameters for Harmony v2 GPU batch correction

    Attributes:

    Name Type Description
    k int | None

    Number of clusters for k-means clustering. If not provided, it will be automatically determined as min(round(N / 30), 100).
    sigma tuple[float, ...]

    Per-cluster diversity weights. Either a single value (broadcast to all clusters) or a vector of length k.
    theta tuple[float, ...]

    Per-variable diversity penalty. Must be a single value; only one batch covariate is supported on the GPU path.
    lambda_ tuple[float, ...]

    Ridge regression penalty for the linear model. Typically a single value. Ignored when use_dynamic_lambda = True.
    max_iter_kmeans int

    Maximum number of k-means Jacobi sweeps per Harmony round.
    max_iter_harmony int

    Maximum number of Harmony outer iterations.
    epsilon_kmeans float

    Convergence threshold for k-means clustering.
    epsilon_harmony float

    Convergence threshold for Harmony.
    window_size int

    Number of previous iterations to consider when checking convergence.
    alpha float

    Scaling factor for dynamic lambda estimation. Must be in (0, 1). Only relevant when use_dynamic_lambda = True.
    tau float

    Scaling factor for theta based on batch size. A value of 0 disables batch-size scaling of theta.
    batch_proportion_cutoff float

    Cutoff for pruning batches with small proportions during ridge regression.
    use_dynamic_lambda bool

    If True, lambda is estimated dynamically per cluster instead of using the fixed lambda value.
    k_means_iter int

    Maximum number of k-means iterations for the initial centroid computation.
    k_means_init str | None

    Initialisation strategy for k-means.
    fixed bool

    If True, centroids are fixed after initialisation.
    quantise bool

    If True, quantises intermediate values to f16 during k-means.

    GPU Scrublet doublet detection parameters.

    The randomised SVD and the projection of the simulated doublets always run on the GPU; knn_backend picks where the kNN runs. There is no svd_solver: the GPU SVD is always randomised.

    Name Type Description
    sim_doublet_ratio float

    expected_doublet_rate float

    stdev_doublet_rate float

    Uncertainty in the expected doublet rate.
    n_bins_histogram int

    Number of histogram bins for the Otsu threshold.
    manual_threshold float | None

    Manual doublet score threshold; None uses Otsu.
    no_pcs int

    Number of principal components.
    normalisation NormDoubletsDefaults

    The normalisation block.
    hvg HvgDefaults

    The HVG block.
    knn_backend Literal['gpu', 'cpu']

    "gpu" or "cpu".
    knn KnnGpuDefaults | KnnDefaults | None

    The kNN block, KnnGpuDefaults for "gpu" and KnnDefaults for "cpu". None is the backend's block with k = 0, which hands the choice of k to Rust.

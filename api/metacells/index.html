    Meta cells¶

    Meta cell generators, quality metrics, merging and persistence.

    Four generators collapse a store into far fewer meta cells held in memory as a MetaCells: bootstrapped neighbourhoods (hdWGCNA), SEACells, SuperCells and MetaCells2. Start with one of them, then judge the result with the metrics, and run the usual bv.pp, bv.graph and bv.embed calls on the MetaCells itself. save_metacells and load_metacells write and read a meta cell set as a directory.

    What lands where. The generators take a SingleCells or SingleCellsSubset, leave it alone and return a new MetaCells. calc_meta_cell_purity writes mc_purity (and optional label and entropy columns) to the meta cells' obs, calc_diffusion_coordinates writes density_region to obs and dcs, density_dist and regions to mc.other_data, and calc_manifold_metrics writes compactness and separation to obs. get_meta_cell_purity, calc_meta_cell_compactness and calc_meta_cell_separation return a frame and touch nothing. Each meta cell keeps the store cells it aggregates in obs original_cell_idx. merge_meta_cells and meta_cells_per_group return a new object.

    Object types. The generators accept SingleCells and SingleCellsSubset; the metrics and merge_meta_cells take MetaCells.

    mc = bv.metacells.generate_supercells(
    sc, params=bv.params.SupercellParams(graining_factor=20)
)
bv.metacells.calc_meta_cell_purity(mc, sc.obs()["cell_grp"].to_list())
bv.metacells.calc_diffusion_coordinates(mc, sc.cache.knn)
bv.metacells.calc_manifold_metrics(mc)
mc.obs(cols=["meta_cell_id", "mc_purity", "compactness", "separation"])

    From there the meta cells go through the normal chain:

    bv.pp.find_hvg(mc, hvg_no=500)
bv.pp.calculate_pca(mc, no_pcs=10)
bv.graph.find_neighbours(mc)

    Gotchas. Bootstrapped, SEACells and SuperCells read the cached PCA and kNN of the source (or build the kNN again with regenerate_knn=True), so run bv.pp.find_hvg, bv.pp.calculate_pca and bv.graph.find_neighbours on sc first. A stale PCA or kNN raises. Without a kNN, the bootstrapped and SuperCells generators warn and return None, SEACells raises. MetaCells2 works on the raw counts and needs neither. Bootstrapped meta cells overlap; the others partition, and MetaCells2 leaves outlier cells unassigned. The labels for the purity are one per row of the source obs, or one per kept cell. The diffusion map is built from the source kNN, so pass sc.cache.knn, and calc_manifold_metrics needs calc_diffusion_coordinates first. A merged object has several index spaces, so both of them warn and do nothing on it: run them per source before merge_meta_cells. Merging also drops the caches and the HVGs, so redo the chain afterwards. The residual model is not saved.

    Worked through in Meta cells with bixverse.

    		 None

    MetaCells ¶

    MetaCells(
    obs: DataFrame,
    var: DataFrame,
    raw: CsrMatrix,
    norm: CsrMatrix,
    original_assignment: MetaCellAssignment,
    meta_cell_method: str,
    *,
    other_data: dict[str, object] | None = None,
    is_merged: bool = False,

    Meta cells in memory.

    Built by the generators in bixverse.metacells and by merge_meta_cells, not by hand.

    >>> import bixverse as bv
>>> mc = bv.metacells.generate_bt_meta_cells(sc)
>>> bv.pp.find_hvg(mc, hvg_no=2000)
>>> bv.pp.calculate_pca(mc, 30)
>>> bv.graph.find_neighbours(mc)

    Attributes:

    Name Type Description
    raw

    Summed raw counts, meta cells x genes, CSR.
    norm

    The counts normalised to the target size and log1p'd, CSR sharing raw's indices and pointers.
    cache

    Analysis results.
    hvg ndarray | None

    0-based gene indices of the highly variable genes, if selected.
    original_assignment

    Provenance of the meta cells.
    other_data dict[str, object]

    Method-specific extras (SEACells rss / archetypes, MetaCells2 cell_info / rare_gene_modules / selected_genes, diffusion dcs / density_dist / regions, merge sources).
    meta_cell_method

    The generator.
    is_merged

    Built by merge_meta_cells.

    Assemble a meta cell object; the generators and the loader call it.

    Type Description
    ValueError

    Label purity¶

    Meta cell generators, quality metrics, merging and persistence.

    Four generators collapse a store into far fewer meta cells held in memory as a MetaCells: bootstrapped neighbourhoods (hdWGCNA), SEACells, SuperCells and MetaCells2. Start with one of them, then judge the result with the metrics, and run the usual bv.pp, bv.graph and bv.embed calls on the MetaCells itself. save_metacells and load_metacells write and read a meta cell set as a directory.

    What lands where. The generators take a SingleCells or SingleCellsSubset, leave it alone and return a new MetaCells. calc_meta_cell_purity writes mc_purity (and optional label and entropy columns) to the meta cells' obs, calc_diffusion_coordinates writes density_region to obs and dcs, density_dist and regions to mc.other_data, and calc_manifold_metrics writes compactness and separation to obs. get_meta_cell_purity, calc_meta_cell_compactness and calc_meta_cell_separation return a frame and touch nothing. Each meta cell keeps the store cells it aggregates in obs original_cell_idx. merge_meta_cells and meta_cells_per_group return a new object.

    Object types. The generators accept SingleCells and SingleCellsSubset; the metrics and merge_meta_cells take MetaCells.

    mc = bv.metacells.generate_supercells(
    sc, params=bv.params.SupercellParams(graining_factor=20)
)
bv.metacells.calc_meta_cell_purity(mc, sc.obs()["cell_grp"].to_list())
bv.metacells.calc_diffusion_coordinates(mc, sc.cache.knn)
bv.metacells.calc_manifold_metrics(mc)
mc.obs(cols=["meta_cell_id", "mc_purity", "compactness", "separation"])

    From there the meta cells go through the normal chain:

    bv.pp.find_hvg(mc, hvg_no=500)
bv.pp.calculate_pca(mc, no_pcs=10)
bv.graph.find_neighbours(mc)

    Gotchas. Bootstrapped, SEACells and SuperCells read the cached PCA and kNN of the source (or build the kNN again with regenerate_knn=True), so run bv.pp.find_hvg, bv.pp.calculate_pca and bv.graph.find_neighbours on sc first. A stale PCA or kNN raises. Without a kNN, the bootstrapped and SuperCells generators warn and return None, SEACells raises. MetaCells2 works on the raw counts and needs neither. Bootstrapped meta cells overlap; the others partition, and MetaCells2 leaves outlier cells unassigned. The labels for the purity are one per row of the source obs, or one per kept cell. The diffusion map is built from the source kNN, so pass sc.cache.knn, and calc_manifold_metrics needs calc_diffusion_coordinates first. A merged object has several index spaces, so both of them warn and do nothing on it: run them per source before merge_meta_cells. Merging also drops the caches and the HVGs, so redo the chain afterwards. The residual model is not saved.

    calc_diffusion_coordinates ¶

    calc_diffusion_coordinates(
    mc: MetaCells,
    knn: KnnGraph,
    *,
    n_dcs: int = 10,
    k_density: int = 150,
    seed: int = 42,
    verbose: Verbose = True,
) -> None

    Diffusion map of the source cells and a density region per meta cell.

    Builds multiscale diffusion components off the source kNN, takes the distance to the k_density-th neighbour in that space as a density proxy and tags its lower quartile "high", upper quartile "low", the rest "mid". Each meta cell gets the most common region of its cells in obs density_region (ties to the name that sorts first); other_data gains dcs, density_dist and regions.

    A merged object warns and is left alone: its memberships live in several index spaces.

    Parameters:

    Name Type Description Default
    mc MetaCells

    The meta cells.

    		 required
    knn KnnGraph

    The kNN of the source cells, one row per kept cell in the source's cells_to_keep order, e.g. sc.cache.knn.

    		 required
    n_dcs int

    Diffusion components.

    		 10
    k_density int

    The neighbour giving the density.

    		 150
    seed int

    Seed.

    		 42
    verbose Verbose

    0 (False) silent, 1 (True) progress, 2 extra detail where the method has it.

    		 True

    Raises:

    Type Description
    ValueError

    If the kNN does not cover the kept source cells.
    References

    Persad, et al., Nat Biotechnol, 2023.

    calc_manifold_metrics ¶

    calc_manifold_metrics(mc: MetaCells) -> None

    Compactness and separation of each meta cell in the diffusion map.

    Compactness is the mean variance over the diffusion components of a meta cell's cells, lower is better; separation the distance from its centroid to the nearest other centroid, higher is better. Both go to obs. Needs calc_diffusion_coordinates first; without it, or on a merged object, a warning and nothing changes.

    merge_meta_cells ¶

    merge_meta_cells(
    inputs: Sequence[MetaCells] | dict[str, MetaCells],
    *,
    source_ids: Sequence[str] | None = None,
    feature_space: str = "intersect",
    prefix_ids: bool = True,
    verbose: Verbose = True,
) -> MetaCells

    Row-bind several MetaCells into one.

    The typical case is sample-pure meta cells, generated per patient and merged so that downstream methods run across the full set. The normalised counts carry over: they are normalised per meta cell, so row-binding leaves them valid. Caches and HVGs are per source and dropped.

    original_cell_idx stays in each source's index space, which is why the diffusion and manifold metrics refuse a merged object.

    Parameters:

    Name Type Description Default
    inputs Sequence[MetaCells] | dict[str, MetaCells]

    The meta cells; a dict names them by source.

    		 required
    source_ids Sequence[str] | None

    Source ids, unique, one per input. None takes the dict keys, else source_01, source_02, ...

    		 None
    feature_space str

    "intersect" or "union" of the gene spaces; with "union" a gene an input lacks is a structural zero for its meta cells.

    		 'intersect'
    prefix_ids bool

    Prefix the meta cell ids with "<source_id>__". Without it, ids repeated across inputs are an error.

    		 True
    verbose Verbose

    0 (False) silent, 1 (True) progress, 2 extra detail where the method has it.

    		 True

    Returns:

    Type Description
    MetaCells

    The merged meta cells, is_merged set, a source_id obs column and
    MetaCells

    the source ids in other_data["sources"].

    Raises:

    Type Description
    ValueError

    On no inputs, mismatched methods or ids, or an empty gene intersection.

    Examples:

>>> mc_b = bv.metacells.generate_supercells(sc, seed=1)
>>> merged = bv.metacells.merge_meta_cells({"a": mc_a, "b": mc_b})

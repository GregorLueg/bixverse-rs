    Annotation¶

    Cell type annotation with ScType and reference mapping with Symphony.

    ScType scores every cell against marker gene sets and calls a type per cell, optionally per cluster. Symphony builds a Harmony-corrected reference from an annotated experiment, maps a query into its embedding and transfers the labels by kNN vote. Start with prepare_cell_markers, calc_sc_type_scores and assign_sc_type for ScType, build_symphony_ref, map_symphony_query and transfer_labels_symphony for Symphony.

    What lands where. The ScType functions leave the experiment alone and return frozen records (ScTypeResults, ScTypeCellResults); put a call into obs yourself. map_symphony_query writes the query embeddings to query.cache.embeddings as "symphony" (corrected), "symphony_pca" (projected) and "symphony_r" (soft cluster assignments). transfer_labels_symphony writes predicted_<column> and confidence_<column> to the query's obs and returns them. build_symphony_ref and add_symphony_labels return a SymphonyReference and touch neither experiment. A reference is immutable: adding labels gives you a new one. All functions take a SingleCells.

    ScType wants markers as a frame of cell_type and gene_id, in the id type of the experiment, and scores the kept cells. The neighbour graph smooths the scores, so run bv.graph.find_neighbours first; clusters from bv.graph.find_clusters add a per cluster call.

    import polars as pl

genes = sc.gene_ids().tolist()
marker_df = pl.DataFrame(
    {
        "cell_type": ["type_1"] * 10 + ["type_2"] * 10 + ["type_3"] * 10,
        "gene_id": genes[:30],
    }
)
markers = bv.annotate.prepare_cell_markers(sc, marker_df)
scores = bv.annotate.calc_sc_type_scores(sc, markers)
calls = bv.annotate.assign_sc_type(sc, scores, cluster_col="leiden_clustering")
sc.add_obs(pl.DataFrame({"cell_idx": sc.cells_to_keep, "sc_type": calls.hybrid}))

    Symphony needs the reference's HVGs, so run bv.pp.find_hvg on it first and hand sc.map.hvg over. Genes match by id; a reference HVG missing from the query becomes a zero column:

    ref = bv.annotate.build_symphony_ref(
    sc, "sample_id", sc.map.hvg, label_columns=["cell_grp"]
)
bv.annotate.map_symphony_query(ref, query, batch_column="sample_id")
pred = bv.annotate.transfer_labels_symphony(ref, query, "cell_grp")

    Gotchas. Every index is 0-based: marker genes, HVGs and cluster ids. cluster_col of assign_sc_type has to be a non-negative integer obs column with a value for every scored cell, which is what find_clusters writes. Without a neighbour graph assign_sc_type warns and scores without smoothing. calls.hybrid is None unless you gave a cluster_col; calls.assignments is the per cell call, null where the cell is Unknown. Labels are stored in a reference in cells_to_keep order, so add_symphony_labels needs the cell set the reference was built on. transfer_labels_symphony raises on a query that has no current "symphony" embedding: map again after the cell filter moves. save_symphony_ref and load_symphony_ref use one .npz file.

    Worked through in Clustering, cell type annotation and reference mapping.

    A Symphony reference.

    Holds the PCA loadings, the per-HVG scaling statistics, the soft cluster centroids and the cached compression terms (nr, c_cache) that map a query without the reference cells, plus the Harmony-corrected embedding for label transfer. Everything numeric is float32, as computed.

    Attributes:

    hvg_gene_names list[str]

    HVG gene ids in loading row order.
    gene_means ndarray

    Per-HVG mean of the normalised reference data.
    gene_sds ndarray

    Per-HVG standard deviation of the normalised reference data.
    loadings ndarray

    PCA gene loadings, (n_hvgs, d).
    z_corr ndarray

    Harmony-corrected embedding, (N, d).
    centroids ndarray

    Cosine-normalised centroids, (K, d).
    nr ndarray

    Cluster sizes, the row sums of r, (K,).
    c_cache ndarray

    The compression term r @ z_corr, (K, d).
    no_pcs int

    Number of principal components.
    harmony_backend str

    "v1" or "v2".
    batch_vars list[str]

    The batch columns of the build.
    slim bool

    Whether z_orig and r were dropped.
    z_orig ndarray | None

    Pre-Harmony PCA scores, (N, d); None when slim.
    r ndarray | None

    Soft cluster assignments, (K, N); None when slim.
    labels DataFrame | None

    Reference cell labels in z_corr row order, or None.
    References

    Kang, et al., Nat Commun, 2021.

Start with prepare_cell_markers, calc_sc_type_scores and assign_sc_type for ScType, build_symphony_ref, map_symphony_query and transfer_labels_symphony for Symphony.

    What lands where. The ScType functions leave the experiment alone and return frozen records (ScTypeResults, ScTypeCellResults); put a call into obs yourself. map_symphony_query writes the query embeddings to query.cache.embeddings as "symphony" (corrected), "symphony_pca" (projected) and "symphony_r" (soft cluster assignments). transfer_labels_symphony writes predicted_<column> and confidence_<column> to the query's obs and returns them. build_symphony_ref and add_symphony_labels return a SymphonyReference and touch neither experiment. A reference is immutable: adding labels gives you a new one. All functions take a SingleCells.

    ScType wants markers as a frame of cell_type and gene_id, in the id type of the experiment, and scores the kept cells. The neighbour graph smooths the scores, so run bv.graph.find_neighbours first; clusters from bv.graph.find_clusters add a per cluster call.

    import polars as pl

genes = sc.gene_ids().tolist()
marker_df = pl.DataFrame(
    {
        "cell_type": ["type_1"] * 10 + ["type_2"] * 10 + ["type_3"] * 10,
        "gene_id": genes[:30],
    }
)
markers = bv.annotate.prepare_cell_markers(sc, marker_df)
scores = bv.annotate.calc_sc_type_scores(sc, markers)
calls = bv.annotate.assign_sc_type(sc, scores, cluster_col="leiden_clustering")
sc.add_obs(pl.DataFrame({"cell_idx": sc.cells_to_keep, "sc_type": calls.hybrid}))

    Symphony needs the reference's HVGs, so run bv.pp.find_hvg on it first and hand sc.map.hvg over. Genes match by id; a reference HVG missing from the query becomes a zero column:

    ref = bv.annotate.build_symphony_ref(
    sc, "sample_id", sc.map.hvg, label_columns=["cell_grp"]
)
bv.annotate.map_symphony_query(ref, query, batch_column="sample_id")
pred = bv.annotate.transfer_labels_symphony(ref, query, "cell_grp")

    Gotchas. Every index is 0-based: marker genes, HVGs and cluster ids. cluster_col of assign_sc_type has to be a non-negative integer obs column with a value for every scored cell, which is what find_clusters writes. Without a neighbour graph assign_sc_type warns and scores without smoothing. calls.hybrid is None unless you gave a cluster_col; calls.assignments is the per cell call, null where the cell is Unknown. Labels are stored in a reference in cells_to_keep order, so add_symphony_labels needs the cell set the reference was built on. transfer_labels_symphony raises on a query that has no current "symphony" embedding: map again after the cell filter moves. save_symphony_ref and load_symphony_ref use one .npz file.

    map_symphony_query ¶

    map_symphony_query(
    reference: SymphonyReference,
    query: SingleCells,
    *,
    batch_column: str | None = None,
    additional_batch_columns: Sequence[str] | None = None,
    params: SymphonyMapParams | None = None,
    verbose: Verbose = True,
) -> None

    Map a query onto a reference.

    Projects the query through the reference loadings and applies the cached mixture-of-experts correction. Genes match by id against the reference HVGs; HVGs the query lacks are zero columns. Writes query.cache.embeddings["symphony"] (corrected), ["symphony_pca"] (projected) and ["symphony_r"] (soft assignments, (N_q, K)).

    Parameters:

    Name Type Description Default
    reference SymphonyReference

    The reference.

    		 required
    query SingleCells

    The query experiment.

    		 required
    batch_column str | None

    obs column with the query batch. None skips the correction, so "symphony" equals "symphony_pca".

    		 None
    additional_batch_columns Sequence[str] | None

    Further obs columns to correct for.

    		 None
    params SymphonyMapParams | None

    The mapping parameters. None uses the defaults.

    		 None
    verbose Verbose

    0 (False) silent, 1 (True) progress, 2 extra detail where the method has it.

    		 True

    Raises:

    Type Description
    ValueError

    If a batch column is missing or incomplete.
    References

    Kang, et al., Nat Commun, 2021.

    Examples:

    >>> bv.annotate.map_symphony_query(ref, query, batch_column="sample_id")
>>> embedding = query.cache.embeddings["symphony"]

    transfer_labels_symphony ¶

    transfer_labels_symphony(
    reference: SymphonyReference,
    query: SingleCells,
    label_column: str,
    *,
    knn_params: KnnParams | None = None,
    seed: int = 42,
    verbose: Verbose = True,
) -> DataFrame

    kNN majority vote of reference labels onto a mapped query.

    The reference z_corr is indexed, the query's "symphony" embedding searched. A missing reference label is its own class, so a query cell can come back null. Ties go to the label sorting last (the crate's max_by_key). The two columns are also written to the query's obs.

    Parameters:

    Name Type Description Default
    reference SymphonyReference

    The reference, with stored labels.

    		 required
    query SingleCells

    The query, mapped with map_symphony_query.

    		 required
    label_column str

    A stored label column.

    		 required
    knn_params KnnParams | None

    The kNN parameters. None uses the defaults; distances on z_corr are typically Euclidean.

    		 None
    seed int

    Seed for the index build.

    		 42
    verbose Verbose

    0 (False) silent, 1 (True) progress, 2 extra detail where the method has it.

    		 True

    Returns:

    Type Description
    DataFrame

    predicted_<label_column> and confidence_<label_column> (the
    DataFrame

    winning vote share) per kept query cell, in cells_to_keep order.

    Raises:

    Type Description
    ValueError

    If the reference has no such labels, or the query has no current "symphony" embedding.
